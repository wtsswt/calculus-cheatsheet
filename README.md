# 高等数学必背手册

Calculus I Cheatsheet — 高等数学（第一学期）必背速查手册。单文件网页，双击即开，断网可用，可打印。

- **在线访问**：https://wtsswt.github.io/calculus-cheatsheet/
- **仓库地址**：https://github.com/wtsswt/calculus-cheatsheet
- **本地打开**：`index.html`

## 里面有什么

六章 48 张卡片：极限与无穷小 / 导数与微分 / 泰勒展开 / 不定积分 / 三角公式全表 / 附录。

每条按标记分级：必背 33、会用 14、了解 1。

## 怎么用

- `/` 聚焦搜索，输「降幂」「sec」「泰勒」直接定位
- 顶部点「必背」，只看闭卷要默写的那些
- 点「自测」，公式全部模糊，点击逐条揭示——考前用来查默写
- ⌘P 直接打印，A4 双栏，卡片不跨页切断
