- **在线访问**：https://wtsswt.github.io/calculus-cheatsheet/
- **仓库地址**：https://github.com/wtsswt/calculus-cheatsheet
- **本地打开**：`index.html`

## 里面有什么

六章 47 张卡片：极限与无穷小 / 导数与微分 / 泰勒公式 / 不定积分 / 三角公式全表 / 附录。

覆盖 §1.6–§4.2：两个重要极限、无穷小的阶与等价替换、导数定义与十六条导数公式、高阶导数与莱布尼茨、泰勒两种余项与七个展开式、基本积分表与凑微分、三角公式十二组；附录给推导主线、第二类换元回代表、按被积式查表与四条易错。

## 怎么用

- `/` 聚焦搜索，输「降幂」「sec」「泰勒」直接定位
- 点「自测模式」，公式全部模糊，点击逐条揭示——考前用来查默写
- ⌘P 直接打印，A4 双栏，卡片不跨页切断
