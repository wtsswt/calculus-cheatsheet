## 怎么用

- `/` 聚焦搜索，输「降幂」「sec」「泰勒」直接定位
- 点「自测模式」，公式全部模糊，点击逐条揭示，用于考前查默写
- ⌘P 打印，A4 双栏，卡片不跨页切断

公式用 KaTeX 渲染，KaTeX 已内联进 HTML，离线打开照常渲染。347 条公式均通过 KaTeX 语法校验。
